An entry for the [make.fun](https://make.fun) bounty
[The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf):
a program that writes one line — the funniest out-of-office
auto-reply — to `/output/entry.txt`.

## The line

> I'm out until Monday. This auto-reply is the fastest reply I've ever sent you.

## Run

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
